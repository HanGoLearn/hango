## Alcance y criterios

- Cada lección tiene selección editorial propia de núcleo, apoyo, ampliación y
  apertura en el papel del personaje. No se eligen automáticamente las primeras
  palabras ni se exige agotar vocabulario, gramática o preguntas.
- Los **600 registros léxicos y 180 gramaticales** actuales se conservan entre
  bancos, con sus IDs, significados y pinyin. Los homógrafos no se fusionan.
  El resto del contenido actual que no es núcleo ni ampliación queda como apoyo.
- Los compañeros de escenario son candidatos de reciclaje, no prerrequisitos
  obligatorios. Solo un paso real VOCABULARY/GRAMMAR completado por la misma
  cuenta permite añadir su contenido al apoyo; completar otro paso no sirve.
  Exposición indirecta no acredita dominio ni la versión exacta vista.
- El catálogo no se descarga desde los componentes de voz: se separan contrato
  compartido y selección editorial. El servidor consulta la lección actual y
  hasta ocho candidatas relacionadas, no todo Fundamentos. Cada consulta filtra
  contenido publicado y el progreso de la cuenta autenticada, sin caché global.
- Se conservan los topes: apoyo total de 16 palabras/6 patrones, ampliación
  léxica de cuatro entradas y 12 frases actuales si su paso DIALOGUE está
  completado. Cada lección auditada tiene diez palabras y tres patrones;
  la consulta admite hasta 20/8, sin truncar esas fichas actuales.
- El contrato conversacional, ayuda ES/EN, tiempos, turnos y despedidas se
  mantienen. La misma representación se usa en sesión, respuesta y cierre.
  No se cambia la evaluación, puntaje, cobertura, presupuesto ni límite de IA.
- No se cambian Han Tutor, Companion, Speaking Lab o Placement. Tampoco los
  bloqueos de acceso existentes. Dos lecciones de desplazamientos conservan
  dificultad INTERMEDIATE dentro del capítulo Fundamentos.
- Las escenas de farmacia, banco y transporte son simulaciones lingüísticas:
  sin inventar dosis, eficacia, datos privados, rutas reales o trámites realizados.

## Familias y andamiaje

| Escenarios      | Progresión recomendada, no bloqueo                                                            |
| --------------- | --------------------------------------------------------------------------------------------- |
| Primeros pasos  | Identidad → tiempo → petición concreta → ubicación/dirección.                                 |
| Familia         | Cantidad/miembros → edad/descripción → ubicación/duración → actividades. No inventar familia. |
| Clima           | Estado/previsión ficticia → preferencia → ropa → condición y cambio de plan.                  |
| Vida diaria     | Sensación → hora/secuencia → día vivido → contraste con fin de semana.                        |
| Casa            | Existencia/cantidad → posición/clasificadores → tareas/frecuencia → vecindario.               |
| Compras básicas | Artículo/color → talla/ajuste → precio/pago → problema/solución. Piloto conservado.           |
| Teléfono        | Identificación y propósito → mensaje → reparación de malentendido → cita acordada.            |
| Escuela         | Lugar/estudios → permiso para objeto → horario → relato de acciones completadas o pendientes. |
| Pasatiempos     | Preferencia/frecuencia → habilidad con 得 → experiencia/opinión → comparación.                |
| Cuerpo          | Parte/molestia → síntoma/duración → preguntas sobre etiqueta ficticia → consejo cotidiano.    |
| Dinero          | Deseo/cantidad → problema y resultado → total/medio de pago → gasto/comparación.              |
| Lugares         | Localización → horas/estado → opinión del vecindario → ruta con referencias.                  |
| Opiniones       | Preferencia → comparación → acuerdo/desacuerdo → razón antes de concesión.                    |
| Planes          | Experiencia/evento → intención/predicción → cambio acordado → relato breve ordenado.          |
| Desplazamientos | Destino/coste → ruta/transbordo → instrucciones por tramos → reserva ficticia.                |

Se reciclan selecciones de escenarios cercanos solamente si el alumno completó
sus pasos relevantes. Una respuesta breve o distinta del ejemplo no desencadena
un cuestionario, una subida automática de dificultad ni una nueva lección.
Las ampliaciones se usan por iniciativa/petición del alumno o varios intercambios
adecuados; nunca durante preparación del cierre o despedida.
