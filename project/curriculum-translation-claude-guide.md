# HanGo curriculum translation handoff — Claude

## Purpose

Translate one exported HanGo curriculum scenario from canonical English into
natural Latin American Spanish. This is authored learner-facing content only.
It is not a code-editing task.

## File contract

You will receive one JSON file generated by HanGo. Edit **only** the value of
each `units[].translation` field.

Do not edit:

- `source`, `key`, `entityType`, `entityId`, `field`, or `context`;
- `schemaVersion`, `targetLocale`, `generatedAt`, `scenario`, `sourceHash`,
  `translationBaselineHash`, or `instructions`;
- the order of units or the JSON structure.

Return valid JSON only. Do not wrap it in Markdown and do not include a prose
introduction or conclusion.

## Editorial standard

- Use clear, natural, concise neutral Latin American Spanish.
- Address the learner as **tú** where the English copy addresses the learner.
- Translate the pedagogical meaning, not word-for-word English syntax.
- Preserve the difficulty and amount of guidance of the source. Do not add
  explanations, examples, answers, or cultural facts that are absent.
- Use consistent teaching terminology: _escenario_, _lección_, _objetivo_,
  _diálogo_, _vocabulario_, _gramática_, _ejercicio_, _pista_, _misión_ and
  _criterio de evaluación_.
- Preserve product and feature names such as **HanGo**, **Han**,
  **HanVocabulary**, **Speaking Lab**, **Learning Journey**, **HanCoins** and
  **HSK** unless the source already uses a localized product label.

## Protected content

Every Chinese fragment, pinyin fragment, placeholder, URL and formatting token
inside `source` must appear unchanged in `translation`. Do not simplify Chinese
characters, alter tones, romanize Chinese, or translate Mandarin answers.

The package intentionally excludes audio, scoring, correct answers, reference
answers, ordering, levels and Han's prompts/personality. Do not attempt to add
or reconstruct any of them.

## Quality check before returning

1. Every `translation` is non-empty.
2. The Spanish reads naturally in its supplied `context`.
3. Chinese and protected tokens match the source exactly.
4. No JSON key, ID, source string, structure, or unit order changed.
5. The result contains only the complete JSON document.
