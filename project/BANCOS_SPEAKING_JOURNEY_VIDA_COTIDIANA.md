## Familias y andamiaje recomendado

Estas relaciones ayudan a formular una conversación; no imponen prerrequisitos
ni una nueva ruta obligatoria. La selección exacta de apoyo depende de la
exposición real registrada, no del supuesto de haber terminado todo Fundamentos.

| Escenario          | Progresión recomendada                                                                                                     |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| Restaurante        | Petición/orden → ingredientes o restricción → reparación → cuenta/pago. No exigir todos los actos.                         |
| Compras            | Producto/atributo → comparación/descuento → ajuste → condición de cambio o devolución.                                     |
| Hotel              | Reserva/detalle faltante → servicio elegido → problema y alternativa → extensión o salida.                                 |
| Amistades          | Presentación natural → interés realmente compartido → invitación aceptable o declinable → contacto opcional.               |
| Salud              | Síntoma expresado/duración → pregunta sobre información ficticia → emergencia simulada o trámite; nunca prescripción real. |
| Supermercado       | Necesidad/falta → cantidad y precio por peso → comparación → reparto acordado de comidas/tareas.                           |
| Cafetería          | Orden y solo opciones faltantes → noticias aportadas → charla de espera → propuesta para otra ocasión.                     |
| Gimnasio           | Opciones de membresía → horario/disponibilidad → meta expresada → lenguaje para describir una lesión, no tratarla.         |
| Alquiler           | Distribución/instalaciones → renta/inclusiones → negociación → aclaración de términos ficticios antes de aceptar.          |
| Correos            | Destino/peso → método y diferencia de precio → seguimiento simulado → pérdida solo si se confirma en la escena.            |
| Eventos sociales   | Presentación/conexión con anfitrión → interés → cumplido contextual → despedida sin volver a preguntar.                    |
| Planes y clima     | Pronóstico ficticio → condición y alternativa → cambio aceptable → confirmación de datos realmente acordados.              |
| Compañeros de piso | Problema concreto → efecto → propuesta de reparto/límite/remedio → acuerdo sin culpa inventada.                            |
| Compra en línea    | Consulta → estado ficticio → contraste pedido/recibido → solicitud de solución condicionada, no reembolso garantizado.     |
| Entrevista laboral | Trayectoria real o ficticia → ejemplo pertinente → expectativa negociable → preguntas propias del candidato.               |

## Riesgos del contenido que no deben reproducirse como hechos

- El diálogo de supermercado contiene un total que no concuerda con los
  precios/cantidades antes dichos. La orientación pide cifras ficticias
  coherentes, no reutilizar ese total. No se reescribió el diálogo publicado.
- Los diálogos de salud incluyen instrucciones, diagnósticos o promesas que
  no son consejo médico válido para una persona real. Los bancos establecen
  límites: no inventar fármacos/dosis/eficacia ni asegurar recuperación,
  intervención o despacho de una ambulancia. Si se declara una emergencia real,
  salir de la simulación y dirigir a servicios locales de emergencia.
- El diálogo de lesión sugiere un plazo fijo de retorno al ejercicio: el
  personaje no debe prometerlo ni dar tratamiento. La revisión lingüística y
  de seguridad del contenido fuente se mantiene como tarea aparte.
- Renta, reembolsos, seguro y salario usan términos/políticas/importes ficticios,
  no normas legales, precios actuales o derechos/beneficios garantizados.
  Contactos, documentos y números de seguimiento pueden ser inventados; no
  se solicita información privada real ni se ejecuta un trámite.
- Una despedida social dentro de la escena no es un comando técnico de End.
  No obliga a llenar el tiempo con nuevos temas o contactos. Los controles y
  el cierre de Journey conservan su coordinación previa.

## Pruebas, límites de aceptación y continuación

Resultado local: **558 pruebas focalizadas en 15 suites** y **cuatro
integraciones en Postgres desechable** pasan, además de tipos y lint dirigido.
La integración recorre las 120 lecciones revisadas y compara cada ID publicado
de vocabulario/gramática con el banco resuelto. Verifica exposición independiente
por cuenta y paso, y compara el progreso antes/después sin modificaciones.
La herramienta retiró la base de prueba; las bases persistentes no se tocaron.

Las pruebas comprueban las 60 particiones, registros exactos, ampliaciones
existentes, candidatos acotados, separación de cuentas/pasos y ausencia de
cambios de progreso. Las selecciones de Fundamentos siguen verificadas y
los componentes de voz no importan los catálogos de ninguno de los capítulos.
No hay llamadas de voz/modelo reales durante estas verificaciones.

prueba oral representativa para continuidad, ritmo, ayuda ES/EN, datos ya
respondidos, desviaciones y cierre. Las orientaciones de seguridad tampoco
certifican por sí solas cumplimiento real. No se declara toda la matriz completa.
