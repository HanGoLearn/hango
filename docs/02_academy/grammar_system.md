# HanGo Grammar System

Version: 1.0

Status: Official

Last Updated: August 2026

---

# Purpose

This document defines how grammar is taught, reinforced, practiced, and evaluated inside HanGo.

Grammar should never be taught as isolated rules. Instead, grammar serves as a tool that enables learners to communicate more effectively in real-world situations.

---

# Grammar Philosophy

Grammar exists to improve communication.

Learners should understand:

- When to use a grammar structure.
- Why it is used.
- How it changes meaning.
- How native speakers naturally use it.

Grammar should always appear within meaningful contexts.

---

# Learning Sequence

Every grammar point follows the same instructional sequence.

```
Context

↓

Observation

↓

Explanation

↓

Examples

↓

Guided Practice

↓

Speaking

↓

Writing

↓

AI Practice

↓

Simulation

↓

Review
```

---

# Context First

Grammar is first encountered inside a dialogue or realistic situation.

The learner should naturally observe the structure before receiving an explanation.

---

# Explanation

Every grammar explanation includes:

- Purpose.
- Structure.
- Usage.
- Meaning.
- Common situations.
- Comparison with similar grammar.

The explanation should be concise, practical, and focused on communication.

---

# Grammar Examples

Each grammar point includes multiple examples.

Every example contains:

- Chinese characters.
- Pinyin.
- English translation.
- Natural usage.

Examples should gradually increase in complexity.

---

# Common Mistakes

Each grammar point includes a section explaining frequent learner errors.

Examples include:

- Incorrect word order.
- Misuse of particles.
- Confusion with similar structures.
- Literal translations from other languages.

The AI Teacher should reinforce these points during practice.

---

# Guided Practice

Exercises are highly controlled.

Possible activities include:

- Sentence ordering.
- Fill in the blank.
- Pattern transformation.
- Multiple choice.
- Error correction.

The objective is to build confidence before free production.

---

# Speaking Integration

Grammar must immediately appear in speaking activities.

Examples:

- Role-play.
- Guided conversation.
- Pronunciation practice.
- Shadowing.

Learners should actively produce the target grammar.

---

# Writing Integration

Learners reinforce grammar through writing.

Activities include:

- Sentence creation.
- Short responses.
- Messages.
- Paragraph writing.

The AI Teacher provides corrections and explanations.

---

# AI Practice

The AI Teacher generates additional practice based on learner performance.

Possible activities:

- New examples.
- Extra exercises.
- Mini conversations.
- Personalized explanations.

---

# Simulation Integration

Grammar should naturally appear inside simulations.

The learner is expected to use the target structure without being explicitly instructed to do so.

The Simulation Engine evaluates whether the grammar is used appropriately.

---

# Grammar Review

Previously learned grammar should appear regularly.

Review occurs through:

- Future lessons.
- Dialogues.
- Simulations.
- Speaking Lab.
- Writing Lab.
- AI conversations.

Grammar should never be studied only once.

---

# Grammar Progression

Grammar difficulty increases through:

- Sentence length.
- Number of clauses.
- Abstract concepts.
- Formality.
- Naturalness.

Learners should never experience abrupt jumps in complexity.

---

# AI Teacher Responsibilities

The AI Teacher should:

- Explain grammar clearly.
- Compare similar structures.
- Generate additional examples.
- Correct mistakes.
- Encourage active use.
- Adapt explanations to learner level.

---

# Success Definition

The Grammar System succeeds when learners use grammar naturally to communicate rather than simply recalling rules from memory.
