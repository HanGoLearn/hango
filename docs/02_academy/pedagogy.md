# HanGo Pedagogy

Version: 1.0

Status: Official

Last Updated: August 2026

---

# Purpose

This document defines the educational methodology behind HanGo.

It establishes how Chinese should be taught inside the platform and ensures that every lesson, exercise, dialogue, and AI interaction follows the same learning philosophy.

---

# Educational Philosophy

HanGo believes that language learning is the development of communication ability.

Knowing words and grammar rules is not enough.

A learner truly knows Chinese when they can use it to understand information, express ideas, solve problems, and interact with other people.

---

# Core Principle

## Competence Before Knowledge

Traditional learning often measures knowledge:

- Number of words memorized.
- Number of grammar points studied.
- Number of lessons completed.

HanGo measures competence:

- Can the learner communicate?
- Can the learner understand?
- Can the learner express ideas?
- Can the learner use Chinese in real situations?

---

# Learning Through Context

Chinese should always be learned inside meaningful contexts.

Instead of:

```
Word:

预约

Meaning:

Make an appointment
```

HanGo teaches:

```
Situation:

Making a doctor's appointment.

Goal:

The learner can schedule, change, and confirm an appointment.
```

The context creates understanding.

---

# Communication Goals

Every learning unit must have a communication objective.

Examples:

Instead of:

"Learn 20 restaurant words."

The objective becomes:

"Order food, ask questions about ingredients, and communicate preferences in a restaurant."

---

# Four Language Skills Integration

HanGo treats language as an interconnected system.

The four skills are:

## Listening

Understanding spoken Chinese.

## Speaking

Producing spoken Chinese.

## Reading

Understanding written Chinese.

## Writing

Producing written Chinese.

Each lesson should combine multiple skills whenever possible.

---

# Active Learning

Learners should produce Chinese frequently.

The platform should prioritize:

- Speaking.
- Writing.
- Answering questions.
- Creating sentences.
- Expressing opinions.

Passive consumption should not dominate the experience.

---

# Progressive Difficulty

Learning should increase gradually.

Difficulty grows through:

## Vocabulary

More words and expressions.

## Grammar

More complex structures.

## Communication

More abstract ideas.

## Speed

More natural speech.

## Independence

Less learner support.

---

# Spaced Reinforcement

Learning requires repetition.

HanGo continuously reinforces previous knowledge.

Previously learned content should appear again through:

- Conversations.
- Reviews.
- Writing tasks.
- Speaking activities.
- New scenarios.

The goal is long-term retention.

---

# Input and Output Balance

A successful learner needs both:

## Input

Receiving Chinese:

- Listening.
- Reading.
- Dialogue exposure.

## Output

Producing Chinese:

- Speaking.
- Writing.
- Conversation.

HanGo should maintain balance between both.

---

# Error Correction Philosophy

Mistakes are part of learning.

Corrections should:

- Explain the reason.
- Provide examples.
- Encourage improvement.

The objective is understanding, not punishment.

---

# Cultural Learning

Language and culture are connected.

HanGo should include cultural context when relevant.

Examples:

- Social etiquette.
- Expressions.
- Communication styles.
- Regional differences.

Learners should understand not only what Chinese means, but how Chinese is used.

---

# AI-Assisted Learning

Artificial Intelligence enhances the educational process.

The AI Teacher should:

- Adapt explanations.
- Create personalized practice.
- Identify weaknesses.
- Provide feedback.
- Support independent learning.

AI should follow HanGo's educational methodology.

---

# Lesson Design Principle

Every lesson should answer:

1. What will the learner be able to do?

2. In what situation will they use it?

3. How will they practice it?

4. How will they know they improved?

---

# Learning Outcome

The final objective of HanGo is to develop independent Chinese users.

Learners should eventually be able to:

- Learn new vocabulary independently.
- Understand authentic content.
- Communicate confidently.
- Continue improving without depending completely on the platform.
