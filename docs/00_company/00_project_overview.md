# HanGo — Project Overview

Version: 1.0

Status: Planning

Product Name: HanGo

---

# Executive Summary

HanGo is an AI-powered Chinese learning platform designed to help learners achieve real communicative competence rather than simply memorizing vocabulary or passing standardized exams.

Unlike traditional language learning applications, HanGo is built around real-life situations, progressive competency development, and continuous interaction with an AI Teacher that accompanies the learner throughout the entire learning experience.

The HSK framework serves as the curricular backbone of the platform, ensuring systematic progression from intermediate to advanced proficiency (HSK 3–9). However, HanGo's primary objective is not exam preparation, but enabling learners to naturally understand, speak, read, and write Chinese in authentic contexts.

# Core Philosophy

HanGo is built upon one fundamental belief:

People do not learn a language by memorizing isolated words.

People learn a language by repeatedly using it inside meaningful situations.

Every feature, lesson, AI interaction, exercise and recommendation inside HanGo exists to reinforce this philosophy.

# Learning Philosophy

HanGo teaches communication first.

Vocabulary is introduced only when necessary.

Grammar exists to express ideas.

Dialogues simulate real life.

Exercises reinforce competencies.

AI provides personalized guidance.

Learning is continuous.

Nothing is learned only once.

Everything returns in increasingly difficult contexts.
